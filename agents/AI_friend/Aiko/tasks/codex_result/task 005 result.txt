## 3. Folder ownership 決策

主要 ownership 已固定為：

- `reconstruction/`：Source、SourceUnit、Observation、單一 Event、Evidence、Period Definition／Assignment、provenance、workflow validation。
- `character/`：八 Domain Period State、cross-period Development、Compiled State、Character Skill Profile。
- `memory/`：Event-referencing Memory、formation decision、retrieval metadata；不保存 Event 副本。
- `skills/`：Capability protocol、registry、runtime capability；不擁有 canonical proficiency。
- 根目錄 `Aiko/skills/`：可重用的 `SKILL.md` capability resources。
- `knowledge/`：角色可存取的世界／技術資訊。
- `runtime/`：協調及 ephemeral context，不擁有 canonical data。
- `characters/`：僅供模板或 synthetic fixture，不是真實角色 instance。
- Relationship ownership繼續保持 unresolved，未新增獨立 subsystem。

完整矩陣與 artifact routing table 位於 [folder_ownership.md](/C:/AI/agents/AI_friend/Aiko/docs/folder_ownership.md)。

## 6. 修改的 Task 003 contracts

有三項刻意修正：

- `SourceReference` 新增明確的 `approved` 狀態。
- `SourceUnit` 新增 `grounding` 與 `integrity_hash`；未標記內容現在無法通過 validation。
- `EventRecord` 新增 objective facts、character-accessible information、participants、statements、behavior、outcome、uncertainty 等可選欄位。
- `ReconstructionBundle` 新增 Period Definition／Assignment collections。

原因是 v0.0.8 明確要求 approved source boundary、exact-span grounding、Event single source of truth，以及不可跳過 Period Assignment。

既有 Task 003 synthetic tests 已更新為明確 approved、exact-text source，原有 provenance/status 行為保持不變。

## 7. Validation rules

已自動檢查：

- approved Source 與 reference-note 排除。
- exact SourceUnit／immutable exact-span reference。
- locator、integrity hash 與 content mode。
- 全圖 ID 唯一性、missing reference、self-reference、cycle與parent type。
- Event 必須源自 Observation、具 temporal scope，且不得宣告 persistent trait。
- Event 不可重複分配或複製成 domain-specific Event。
- Period order、assignment與candidate boundary。
- 八 Domain slots 與明確 abstention state。
- evidence-bearing domain 不得沒有 Event／Evidence。
- earlier Period 禁止引用 later-period Event。
- Development 必須跨多個 Period State。
- confidence 與 change resistance 保持獨立。
- Causal Hypothesis 必須保留 evidence、uncertainty、alternative hypothesis或counterevidence。
- Memory 必須引用 Event，且不得嵌入第二份 objective Event。
- Memory temporal compatibility與可存取資訊邊界。
- canonical skill proficiency 必須有 SkillEvidence。
- RuntimeCapability 不得改寫 CharacterSkillProfile。
- Compiled State 必須具有版本資訊並追溯至 Period／Development。
- deterministic portable JSON envelope。

## 8. Synthetic tests
