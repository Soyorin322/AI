# Memory

Memory answers what the character experienced or learned and remains separate
from Knowledge. The current Aiko-owned `MemoryRecord` is deliberately generic;
no working/episodic/semantic/relationship taxonomy is part of the stable contract.
Long-term storage, event interpretation, consolidation, summarization, importance,
forgetting, retrieval, and Persona evidence remain deferred. Memory never invokes
the LLM provider directly.
